# 电脑信息报告工具（SysInfoTool）v1.2

一个绿色单文件小工具：采集电脑的硬件、系统、软件、使用痕迹与网络信息，生成**两份交付产物**：
- `*.html` —— **面向人阅读的界面**：按《澄明情报报告》设计语言渲染（详见下文「交付产物设计」）
- `*.json` —— **面向程序/AI 解析**：结构化规范 v1.1，具名字段 + 分组排序 + 美化缩进

## 快速开始

1. 把 `SysInfoTool.exe` 拷到目标机器任意目录（U盘也可以，无需安装）；
2. **建议右键 → 以管理员身份运行**（普通权限也能跑，但 SMART 状态、安全日志、BitLocker 等少数项目会受限）；
3. 点击「开始生成报告」，等待 5–30 秒；
4. 报告生成后自动在浏览器打开，文件保存在 exe 所在目录（`电脑信息报告_YYYYMMDD_HHMMSS.html` / `.json`）。

## 界面选项

图形界面按《澄明情报报告》设计语言重绘（深色渐变页头 + 靛蓝主按钮 + 胶囊开关，见 `preview_gui.png`）；权限等提示以**细条横幅**呈现，不占主界面。

| 选项 | 默认 | 说明 |
|---|---|---|
| 隐藏敏感信息 | ✅ 开启 | 打码序列号、MAC、IP 后两段、用户名、SSID、计算机名，方便把报告发给别人看 |
| 跳过文件夹体积统计 | 关闭 | 大容量硬盘可勾选以加速 |

## 命令行模式

```
SysInfoTool.exe --console            # 无界面直接生成
SysInfoTool.exe --console --no-mask  # 关闭脱敏
SysInfoTool.exe --console --skip-scan --out=D:\报告
```

## 采集内容（26 个模块）

- **硬件**：CPU、主板/BIOS/TPM、内存（含插槽与频率）、硬盘（HDD/SSD、SATA/NVMe、分区使用率、健康状态、BitLocker）、显卡、显示器（EDID：型号/生产年份/尺寸）、网卡（含 WiFi 代数）、声卡、电池健康度（笔记本）、USB 控制器与设备历史
- **系统**：版本/Build/激活渠道、安装日期、更新历史与挂起重启、UEFI/安全启动/快速启动、页面文件、还原点/卷影副本、环境变量
- **软件**：已安装程序、启动项（含禁用状态）、服务、计划任务（非微软）、驱动（含问题设备）、浏览器及书签/扩展、.NET/VC++/DirectX/Java/Python/Node、字体
- **痕迹**：用户目录体积、最近打开文件、回收站、临时文件、RunMRU、地址栏历史、WiFi 配置文件、打印机、蓝牙配对、共享文件夹
- **性能与日志**：Uptime、内存快照、Top 进程、WinSAT 评分、事件日志摘要、蓝屏记录、登录失败统计
- **网络**：IP/网关/DNS/MAC、代理、监听端口与进程

## 按设计不采集（物理或驱动限制）

温度/风扇等传感器、SMART 详细属性（通电时间/剩余寿命）、硬盘测速、内存颗粒 SPD、电源信息、散热器规格、浏览器历史记录（第一版排除）。报告中对应章节均有说明。

## 交付产物设计

### HTML 报告 —— 设计语言《澄明情报报告》（全弹性布局）

为视觉交付产物设计了一套完整的设计语言并严格执行，所有样式通过 CSS 变量（设计令牌）统一管理。布局为**完全弹性**：任意屏幕宽高比下内容都恰好填满、不溢出（已用无头浏览器在 360–3440px 九档视口实测：0 水平溢出）。

| 层级 | 设计 |
|---|---|
| 流体骨架 | `body` 网格 = 弹性侧栏 + `minmax(0,1fr)` 内容区；内容宽度随视口连续填充（实测 477px → 3101px） |
| 流体字号/间距 | 全部字号与留白用 `clamp()` 令牌（--fs-0..6 / --space-1..4），随视口连续缩放 |
| 三态侧栏 | 全宽（≥1240px）→ 图标 rail（平板竖屏/小笔记本，悬停出提示）→ 抽屉（手机） |
| 自适应组件 | 看板卡片 `auto-fit` 自适应列数；**标准 1080P（≥1560px 视口）固定 5 列铺开**（每卡约 288px 铺满整行）；事实值列弹性填满；数据表 100% 填满，过窄时容器内横向滚动 |
| 容器查询 | 内容区按自身宽度再调内部排版（窄容器卡片单列、标签列加宽） |
| 色彩 | 深海军蓝渐变页头 + 靛蓝主色 `#3d5af1` + 状态色（正常绿 / 关注琥珀 / 异常红），每色配套浅底徽章 |
| 字体 | kicker 小标 → 标题（clamp 23–36px）→ 分组标题（宽字距）→ 章节标题 → 表题 → 正文 → 注释，数字等宽对齐；注释限 72ch 行长，超宽屏保持可读 |
| 组件 | 状态徽章、概览事实网格、数据表（表头吸顶/斑马纹/悬停）、折叠明细、信息注释条、失败警示框 |
| 行为 | 滚动监听侧栏高亮、平滑锚点、移动端抽屉导航、回到顶部、打印样式（含深色页头） |

### JSON 报告 —— 结构化规范 v1.1（面向 AI）

JSON 不再是数据模型的裸序列化，而是按“机器可消费”原则重组：

```json
{
  "schema_version": "1.1",
  "meta": { "tool": "...", "version": "1.3.0", "generated_at": "ISO8601",
            "duration_seconds": 7.5, "masked": true, "admin": false,
            "computer_name": "***", "failures_count": 0 },
  "summary": [ { "title": "CPU", "icon": "🧠", "level": "normal", "lines": [...] } ],
  "sections": [
    { "id": "cpu", "title": "CPU（处理器）", "category": "硬件", "order": 10, "icon": "🧠",
      "status": { "level": "ok", "text": "正常" },
      "facts": [ { "name": "型号", "value": "Intel(R)...", "level": "normal" } ],
      "tables": [ { "title": "...", "collapsed": false,
                    "columns": ["插槽","容量",...],
                    "rows": [ { "插槽": "DIMM0", "容量": "16 GB", ... } ],
                    "note": null } ],
      "notes": [...] } ],
  "failures": [ "..."]
}
```

要点：`facts` 由 Tuple 的 Item1/2/3 改为**具名字段**；表格行改为**列名 → 值**的对象（AI 可直接按列名取值）；章节带 `category` 分组并按（分组序 → Order）稳定排序；空状态统一归一化为 `normal`；2 空格缩进美化输出。

## 本地构建

无需安装 .NET SDK，直接使用 Windows 自带的 .NET Framework 编译器：

```
.\build.ps1              # 输出到仓库根目录 SysInfoTool.exe
.\build.ps1 -OutDir .\bin
```

也可用任意支持 SDK 风格项目的 .NET SDK 打开 `Source\SysInfoTool.csproj` 构建。

## 环境要求

- Windows 10 1809+ / Windows 11（x64），无需安装 .NET（系统自带 4.8）
- 单文件约 190KB，零外部依赖，不联网
